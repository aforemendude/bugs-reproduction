jsdiff JSON key order

Change either JSON document and click the button. The numeric-looking keys are intentionally written between ordinary keys so the browser's object-key ordering is visible.

What jsdiff sees

jsdiff sorts keys before serializing. V8 then enumerates integer-like keys first, so "2" and "10" appear before the string keys.
